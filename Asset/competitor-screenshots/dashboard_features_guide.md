# Panduan Fitur & Visualisasi Dashboard: 4D Smart Menu

Dokumen ini berisi rincian seluruh fitur dasbor kompetitor **4D Smart Menu** yang dilengkapi dengan tangkapan layar (*screenshot*) visual untuk mempermudah perancangan UI/UX proyek **3Diner**.

---

## 1. ADMIN CONSOLE (Dasbor Utama & Kontrol Bisnis)

Admin Console adalah pusat kontrol eksekutif bagi pemilik restoran untuk melacak performa bisnis dan mengatur operasional.

### 1.1 Laporan Penjualan (Revenue Analytics)
*   **Fungsi:** Menampilkan grafik garis penjualan harian/bulanan, jumlah transaksi, total hidangan terjual, dan rata-rata pengeluaran per meja.
*   **Visual:** Grafik garis neon biru di atas latar gelap, kartu informasi ringkas (*summary cards*) di bagian atas.
*   **Screenshot:**
    ![Revenue Analytics Chart](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/admin_1min30s_1781953444050.png)

### 1.2 Pelacakan Kecepatan Dapur (Cook Time Analytics)
*   **Fungsi:** Menyajikan statistik waktu rata-rata dapur dalam menyajikan masakan untuk memastikan standar kecepatan layanan terjual.
*   **Visual:** Diagram batang neon hijau yang melacak performa per menit.
*   **Screenshot:**
    ![Cook Time Performance Analytics](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/admin_3min30s_1781953460180.png)

### 1.3 Demografi Perangkat Pelanggan (Device OS Analytics)
*   **Fungsi:** Menampilkan persentase sistem operasi perangkat pelanggan (iOS vs Android) untuk mempermudah pemilik memantau kompatibilitas rendering AR.
*   **Visual:** Diagram donat (*donut chart*) berwarna oranye dan biru.
*   **Screenshot:**
    ![Customer Device OS Analytics](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/admin_5min_1781953485589.png)

### 1.4 Laporan Kinerja Pelayan (Staff Manager Summary)
*   **Fungsi:** Tabel ringkasan performa pelayan, total meja yang diservis, item diantar, dan kontribusi nilai penjualan per pelayan.
*   **Visual:** Tabel abu-abu minimalis yang mudah difilter.
*   **Screenshot:**
    ![Staff Performance Tracking](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/admin_9min30s_1781953549528.png)

### 1.5 Banner Pengumuman Real-time (Smart Alerts)
*   **Fungsi:** Membuat teks pengumuman penting (misal: event live music, menu terbatas) yang akan langsung tampil meluncur di atas layar handphone pelanggan secara real-time.
*   **Visual:** Pengaturan input teks dengan opsi pilihan warna latar belakang banner pengumuman.
*   **Screenshot:**
    ![Smart Alerts Management](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/admin_6min30s_1781953509570.png)

## 2. MENU DESIGNER & AI TOOLS (Dasbor Perancang Menu)

Panel khusus untuk menyusun tampilan menu digital yang akan diakses oleh pelanggan, lengkap dengan perkakas bertenaga AI.

### 2.1 Impor Menu Cepat (AI Menu Extractor)
*   **Fungsi:** Pengguna cukup menyeret file PDF menu lama atau mengunggah foto menu fisik untuk diubah secara otomatis menjadi basis data menu digital dalam satu klik.
*   **Visual:** Box drag-and-drop file terpusat diikuti dengan daftar hasil ekstraksi yang terbagi rapi.
*   **Screenshots:**
    ![AI Menu Extractor Initial Screen](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/one_click_1min_1781953668204.png)
    ![AI Menu Extractor Scanned Output](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/one_click_1min40s_1781953703522.png)

### 2.2 Penyelarasan Model 3D (3D Model Editor & AI Setup)
*   **Fungsi:** Mengubah foto makanan 2D menjadi model 3D menggunakan sistem AI Generator, atau mengunggah manual file model 3D (.glb/.usdz). Dilengkapi editor skala, rotasi, bayangan, dan ketinggian AR.
*   **Visual:** Layar hitam penuh dengan preview model 3D interaktif di tengah dan panel slider penyesuaian parameter di kanan.
*   **Screenshots:**
    ![3D Model Upload Prompt](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/dish_setup_1_1781953840594.png)
    ![3D Model Properties Editor](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/dish_setup_2_1781953862950.png)
    ![AI 3D Model Generation Steps](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/dish_setup_4_1781953928493.png)

### 2.3 Penyunting Detail Hidangan (Walkthrough Editor)
*   **Fungsi:** Panel pengisian deskripsi detail hidangan, penentuan harga, tag rekomendasi koki (*Chef Recommendations*), tingkat kepedasan (*Spicy*), maupun jenis makanan (*Vegan*).
*   **Visual:** Sidebar editor di sebelah kanan yang bergeser masuk secara responsif.
*   **Screenshots:**
    ![Walkthrough Category List](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/walkthrough_1min_1781953298092.png)
    ![Dish Detail Editor](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/walkthrough_3min_1781953316539.png)

### 2.4 Penjadwal Menu & Diskon Otomatis (Scheduler & Happy Hour)
*   **Fungsi:** Pengaturan jam aktif menu tertentu (misal: menu sarapan nonaktif otomatis setelah jam 10 pagi) dan pembuat diskon persen Happy Hour otomatis pada jam-jam sepi pengunjung.
*   **Visual:** Form kalender/jam pengingat minimalis dengan seleksi hari aktif.
*   **Screenshots:**
    ![Multi-Menu Scheduler Settings](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/walkthrough_5min_1781953357589.png)

## 3. STAFF CONSOLE (Dasbor Pelayanan Lantai & Pelayan)

Konsol portabel khusus pelayan (*waiters*) untuk memantau aktivitas pelanggan di lapangan secara langsung.

### 3.1 Denah Lantai Restoran Interaktif (Live Table View Floor Plan)
*   **Fungsi:** Peta interaktif 2D tata letak meja fisik restoran untuk melacak status meja secara real-time berdasarkan kode warna khusus (Merah, Hijau, Emas VIP).
*   **Visual:** Grid meja bulat dan kotak berpenunjuk nomor dengan lampu neon indikator berdenyut (*pulsing notification lights*).
*   **Screenshot:**
    ![Live Table Floor Plan](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/staff_2min_1781953619482.png)

### 3.2 Modifikator Pesanan Aktif (Live Order Modifier)
*   **Fungsi:** Pelayan dapat mengetuk meja aktif pada denah lantai untuk menambahkan menu tambahan, memberikan catatan dapur (seperti *"tanpa es"*), atau menyisipkan menu complimentary gratis.
*   **Visual:** Lembar nota pesanan digital yang ramah sentuhan.
*   **Screenshot:**
    ![Waiter Mobile View Panel](file:///C:/Kerja/3Diner/Asset/competitor-screenshots/staff_1min_1781953600889.png)
