## Risiko hilang diam-diam

Nomor mengikuti nomor baris tabel di atas.

1. **Tombol pemicu "Ekstrak Menu via AI"** — Selector `[&_button]:w-full` ada di parent page.tsx, bukan di komponen. Rebuild yang memindahkan tombol keluar dari wrapper itu diam-diam menghilangkan layout mobile.
2. **Overlay ekstraktor via createPortal + guard hydration** — Kalau rebuild memakai <Dialog> biasa tanpa portal, z-index dan backdrop-filter akan tertimpa stacking context header dashboard.
3. **Kunci scroll body saat modal terbuka + restore nilai lama** — Restore nilai sebelumnya mudah diganti jadi `= ""` saat rebuild; bug baru hanya kelihatan kalau ada modal lain yang bersarang.
4. **Tutup modal: klik backdrop, tombol X, dan reset tertunda 200ms** — Delay 200ms ini murni kosmetik dan hampir pasti dihapus saat rebuild; akibatnya konten modal berkedip kosong saat animasi fade-out.
5. **Animasi masuk overlay & dialog (me-fade / me-pop)** — Keyframes ditulis inline di dalam JSX; kalau rebuild memindah styling ke Tailwind/global CSS, nama kelas .me-overlay/.me-dialog hilang tanpa error.
6. **Dropzone drag & drop file menu** — onDragOver wajib memanggil e.preventDefault(); tanpa itu drop di browser membuka file di tab baru — kegagalan senyap yang tidak memunculkan error.
7. **Filter tipe file & hint batas 15MB di ekstraktor** — Batas 15MB muncul di dua tempat (teks UI dan server). Rebuild yang menyalin teks tapi lupa accept-list membuat drag-drop menerima file yang pasti ditolak server.
8. **Reset nilai input file agar file yang sama bisa dipilih ulang** — Satu baris tanpa efek visual; paling sering hilang saat rebuild dan gejalanya ("tombol tidak merespons pilihan kedua") sulit dilacak.
9. **Progress palsu merangkak selama menunggu Gemini** — Tiga tempat berbeda memanggil clearInterval (sukses, catch, reset). Kelewat satu → timer bocor, progress tetap merangkak di background setelah modal ditutup.
10. **Animasi scanner dokumen saat proses** — Keyframe me-scan pakai empat titik opacity untuk menyembunyikan reset. Rebuild yang menyederhanakan jadi 0%→100% membuat garis terlihat 'terbang balik' ke atas.
11. **Banner error ekstraktor** — Banner ini merangkap dua sumber error (server + validasi lokal). Rebuild yang memisahkannya bisa membuat error validasi tidak pernah tampil karena stage review tidak punya slot error.
12. **Stage review: grid draft yang bisa diedit** — Prefix "Rp" adalah <span> terpisah dari <input>, bukan format currency. Rebuild yang memakai komponen input berformat akan mengubah nilai yang dikirim (mis. jadi string "Rp 45.000").
13. **ID draft stabil (uid) untuk key React** — Klasik: rebuild memakai key={index}. Bug tidak terlihat sampai user menghapus baris di tengah.
14. **Tombol "Ganti file" kembali ke dropzone** — Aksi destruktif tanpa konfirmasi — perilaku eksisting yang harus dipertahankan apa adanya; menambah konfirmasi = perubahan perilaku, menghapus reset penuh = state bocor antar unggahan.
15. **Simpan massal draft (bulkCreateMenus) dengan useTransition** — useTransition dipakai sebagai sumber kebenaran `pending`; kalau rebuild ganti ke useState biasa, tombol bisa ganda-klik dan menyisipkan menu dua kali.
16. **Sanitasi & batas server saat bulk insert menu AI** — Batas panjang ini tidak tercermin di UI (tidak ada maxLength pada input). Rebuild yang menambah maxLength berbeda atau menghapus truncation server akan mengubah data yang tersimpan diam-diam.
17. **revalidatePath setelah bulk insert (tanpa router.refresh di klien)** — Ini satu-satunya mekanisme penyegaran. Rebuild yang menghapus revalidatePath membuat daftar menu terlihat 'tidak menyimpan apa-apa' sampai user reload manual.
18. **Stage done: konfirmasi jumlah menu tersimpan** — Angka berasal dari server (`inserted`), bukan dari panjang daftar lokal. Rebuild yang menampilkan drafts.length akan berbohong ketika server menyaring baris.
19. **Gerbang sesi pada /api/menu/extract** — Karena middleware tidak melindungi /api, menghapus getAuthCafeId di rebuild langsung membuka kuota Gemini server ke publik tanpa error yang terlihat.
20. **Prompt & response schema Gemini untuk ekstraksi menu** — Temperature 0.2 dan responseSchema adalah alasan hasil konsisten. Rebuild yang menyalin prompt tapi lupa generationConfig akan menghasilkan JSON tak terstruktur yang lolos parser tapi kacau isinya.
21. **parseGeminiMenus — normalisasi keluaran AI** — Di-export khusus supaya bisa diuji; rebuild yang meng-inline-kan logika ini ke dalam POST menghapus kemampuan uji dan biasanya ikut menghilangkan penanganan harga string.
22. **Refund credit pada setiap jalur gagal ekstraksi** — Refund tersebar di tiga cabang. Menambah cabang error baru saat rebuild tanpa refund akan membakar jatah kafe untuk hasil yang tidak pernah mereka terima — dan tidak ada error yang muncul.
23. **Tombol "Auto-Isi Detail" (Gemini) di form menu** — Nilai 0 dianggap falsy (baris 151-152), jadi kalori/waktu 0 sengaja tidak menimpa isian user. Rebuild yang mengganti ke `!= null` mengubah perilaku ini.
24. **Flash pulse pada field yang diisi AI** — Ini satu-satunya sinyal 'field mana yang barusan diubah AI'. Murni dekoratif secara kode, tapi menghapusnya membuat user tidak sadar isian manualnya tertimpa.
